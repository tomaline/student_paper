# student_paper
Code for 《ADCG:Adaptive Data Augmentation and Cross-Granularity Graph for Imbalanced Chinese Text Classification》

1.We currently provide the main file and the model file. If the paper is accepted, we will release the complete model code.

2.All data comes from publicly available data files.

THUCNews (Tsinghua University News Classification Dataset).
THUCNews is a Chinese news classification dataset containing approximately 840,000 news articles across 14 categories. A subset of 8,360 samples is used in the experiments, with category sizes ranging from 36 to 1,629 samples. The average text length is approximately 923 characters.

Fudan (Fudan University Chinese Text Classification Dataset).
Fudan is a Chinese text classification dataset containing 9,804 samples from 20 categories, including arts, education, transportation, military, and sports. The dataset exhibits a long-tail distribution, with category sizes ranging from 25 to 1,600 samples. The average text length is approximately 5,371 characters.

SougoCS (Sogou News Text Classification Dataset).
SougoCS is a Chinese news classification dataset covering 11 categories, including finance, sports, technology, automotive, and health. It contains 92,284 text samples, with category sizes ranging from 34 to 37,211 samples. The average text length is approximately 622 characters.

NeteaseNews (Netease News Corpus).
NeteaseNews is a Chinese news classification dataset collected from various channels of the Netease news website. It contains 24,000 samples from 6 categories, with each category containing between 400 and 4,000 samples. The average text length is approximately 979 characters.

The datasets analyzed during the current study are publicly available from their respective repositories. 
The THUCNews dataset is available at \url{https://huggingface.co/datasets/seamew/THUCNews/tree/main}; 
the Fudan dataset can be obtained from \url{https://gitcode.com/open-source-toolkit/283c1}; 
the SogouCS dataset is available at \url{https://vercel.hyper.ai/en/datasets/9270}; 
and the NeteaseNews dataset can be accessed from \url{https://download.csdn.net/download/hashigi_mc/10345013}. 
These publicly available datasets were used solely for academic research purposes.
